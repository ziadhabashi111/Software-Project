# Requirements

- `Project_Description.pdf`: official project description.
- `REQUIREMENTS.md`: readable list of all requirements (104 mandatory, 11 bonus), grouped by module. Use these IDs in branches, commits, PRs and Swagger.
- `SP1_Reviewed_Requirements.xlsx`: the **original, authoritative** course sheet (sheets: Mandatory, Bonus).
- `requirements.csv`: the same data in machine-readable form.
- `reference-data/`: official mock reference data (`countries.csv`, `cities.csv`, `airports.csv` with IANA time zones, `attractions.csv`). The seed script (GEN-12) must load these so IDs match the evaluation.

`REQUIREMENTS.md` and `requirements.csv` are a transcription of the Excel sheet (checked against it: text and complexity match for every requirement). If the course publishes a new version of the sheet, replace the `.xlsx` and update these two files.
