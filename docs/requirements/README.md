# Requirements

- `Project_Description.pdf`: official project description.
- `REQUIREMENTS.md`: readable list of all requirements (104 mandatory, 11 bonus), grouped by module. Use these IDs in branches, commits, PRs and Swagger.
- `requirements.csv` and `SP1_Requirements_transcribed.xlsx`: the same data in machine-readable form.
- `reference-data/`: official mock reference data (`countries.csv`, `cities.csv`, `airports.csv` with IANA time zones, `attractions.csv`). The seed script (GEN-12) must load these so IDs match the evaluation.

The course Excel sheet *Final_ SP1_Reviewed_Requirements.xlsx* is the authoritative source. These files are a transcription of it; if anything differs, the original sheet wins and these files should be corrected.
