# API Documentation

Swagger UI (served by the backend) is the primary API documentation and how Milestone 1 is evaluated: `http://localhost:3000/api/docs`.

Use this folder for extra notes: booking state machine, error format, concurrency approach (holds and overlapping reservations), refund rules, and rendering strategy decisions.

Every endpoint's Swagger entry should reference its requirement ID (e.g. `FLT-22`).
